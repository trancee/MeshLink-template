# Planning: Epics

Authored epic-level story plans for MeshLink features.

## Purpose

Breaks down the product vision into epics (large-grained user stories) with
acceptance criteria and dependency mapping.

## Contents

- `epic-template.md` — Template for new epic planning
- `epics/` — Per-epic planning documents

This directory is **authored** (not generated). Planning artifacts live here
per the spec layout in `SPEC.md` §14.19.
