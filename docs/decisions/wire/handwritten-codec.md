# Wire Codec: Hand-Written vs FlatBuffers

**Status:** Locked — 2026-07-26

## Decision

**Use hand-written Kotlin codec** (not FlatBuffers schema compiler) for all wire frames.

## Rationale

The project spec states: *"the actual wire codec is a FlatBuffers-compatible format implemented in pure Kotlin, not CBOR — see Why pure-Kotlin FlatBuffers for the rationale."*

However, after analysis:

- FlatBuffers compiler (`flatc --kotlin`) generates **mutable Java-style builders** and **table accessors** — not idiomatic Kotlin value classes
- Generated code size: ~2000+ lines for 8 frame types — adds build complexity
- Our frame types are **fixed, small, and performance-critical** — hand-written bit-packed encoding is faster and smaller
- "FlatBuffers-compatible" means **wire-compatible with FlatBuffers vtable layout**, not "generated by flatc"

## What "FlatBuffers-Compatible" Means Here

Our wire format follows FlatBuffers **binary layout conventions**:

- Little-endian
- `uoffset_t` (32-bit) for table offsets
- `soffset_t` (16-bit) for vtable offsets
- Vtable at end of buffer for optional fields
- Scalars at fixed offsets, vectors/strings via offsets

But we **encode/decode manually** in Kotlin for:

1. **Zero allocation** in hot paths (reuse `ByteBuffer`, `ByteArray` pools)
2. **Value class returns** (`PeerIdentity`, `SeqNo`, `SessionId`) — no boxing
3. **Coroutines-friendly** suspending I/O without callbacks
4. **Explicit control** over buffer reuse for cut-through relay

## Frame Encoding Strategy

### Fixed-Size Frames (no vtable needed)

- `ROUTE_DIGEST`: 4 bytes digest + 16 bytes peer = 20 bytes
- `TRANSFER_ACKNOWLEDGMENT`: 8 bytes sessionId + dynamic bitfield
- `KEY_ROTATION`: 64 bytes key + 4 bytes seqno + 64 bytes sig + 1 byte reason = 133 bytes

### Variable-Size Frames (vtable for optional fields)

- `ROUTE_UPDATE`: destination(16) + nextHop(16|0) + source(16) + metric(4) + seqNo(4) + identityKey?(64) + ciphertext
- `MESH_ENVELOPE`: destination(16) + hopLimit(1) + payload (encrypted)

## Hand-Written Codec Structure

```kotlin
// meshlink/src/commonMain/kotlin/ch/trancee/meshlink/wire/WireCodec.kt

sealed interface WireFrame {
    val frameType: FrameType
    fun encode(buffer: ByteBuffer): Int // returns bytes written
    companion object {
        fun decode(buffer: ByteBuffer): Result<WireFrame>
    }
}

// Example: RouteDigest (fixed size, no vtable)
@JvmInline
value class RouteDigestFrame(
    val digest: UInt,
    val peerIdentity: PeerIdentity
) : WireFrame {
    override val frameType = FrameType.ROUTE_DIGEST
    override fun encode(buffer: ByteBuffer): Int {
        buffer.putUInt(digest)           // 4 bytes
        buffer.put(peerIdentity.toByteArray()) // 16 bytes
        return 20
    }
    companion object {
        fun decode(buffer: ByteBuffer): RouteDigestFrame {
            val digest = buffer.getUInt()
            val peer = PeerIdentity.fromBytes(buffer.readBytes(16))
            return RouteDigestFrame(digest, peer)
        }
    }
}
```

## Buffer Management

```kotlin
// meshlink/src/commonMain/kotlin/ch/trancee/meshlink/wire/BufferPool.kt

class BufferPool(private val bufferSize: Int = 1024) {
    private val pool = ArrayDeque<ByteBuffer>()
    private val lock = Any()
    
    fun acquire(): ByteBuffer = synchronized(lock) {
        pool.poll() ?: ByteBuffer.allocateDirect(bufferSize).order(ByteOrder.LITTLE_ENDIAN)
    }
    
    fun release(buffer: ByteBuffer) = synchronized(lock) {
        buffer.clear()
        pool.add(buffer)
    }
}
```

**Usage in cut-through relay:**

```kotlin
suspend fun relayFrame(frame: WireFrame, nextHop: PeerIdentity) {
    val buffer = bufferPool.acquire()
    try {
        frame.encode(buffer)
        buffer.flip()
        hopSession.send(nextHop, buffer)
    } finally {
        bufferPool.release(buffer)
    }
}
```

## Discovery Advertisement Codec

Bit-packed (not FlatBuffers) — 31 bits total:

```kotlin
// meshlink/src/commonMain/kotlin/ch/trancee/meshlink/discovery/AdvertisementCodec.kt

class AdvertisementCodec {
    fun encode(
        version: UInt,      // 3 bits
        platform: UInt,     // 2 bits
        powerMode: UInt,    // 3 bits
        meshHash: UInt,     // 16 bits
        psmHint: UByte,     // 8 bits
        fingerprint: ByteArray // 12 bytes = 96 bits
    ): ByteArray {
        // Total: 3+2+3+16+8+96 = 128 bits = 16 bytes + 4 bytes UUID = 20 bytes
        val buffer = ByteBuffer.allocate(20).order(ByteOrder.LITTLE_ENDIAN)
        buffer.putInt(0x4D455348) // "MESH" UUID
        
        // Pack bits
        var packed = 0L
        packed = (packed shl 3) or version.toLong()
        packed = (packed shl 2) or platform.toLong()
        packed = (packed shl 3) or powerMode.toLong()
        packed = (packed shl 16) or meshHash.toLong()
        packed = (packed shl 8) or psmHint.toLong()
        
        buffer.putLong(packed)
        buffer.put(fingerprint) // 12 bytes
        return buffer.array()
    }
}
```

## Testing

- `WireCodecTest`: Round-trip encode/decode all frame types
- `WireCodecFuzzTest`: Random byte mutation → decode must not crash (fail-closed)
- `WireCodecCompatTest`: Decode fixtures from reference implementation (if any)
- Benchmark: `< 1 µs/message` per `docs/reference/12-build-quality.md`

## Migration Path (If FlatBuffers Needed Later)

1. Write `.fbs` schema matching current wire format
2. Run `flatc --kotlin` → generated code
3. Add `WireCodecFlatBuffers` implementation
4. A/B test vs hand-written; switch if beneficial
5. Keep hand-written as fallback
